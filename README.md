# Petshop

## Descripción

**Petshop** es una aplicación web de comercio electrónico (E-commerce) desarrollada con React que permite a los usuarios explorar un catálogo de productos para mascotas de manera rápida e intuitiva.

Entre sus principales funcionalidades se encuentran:

- Visualizar un catálogo dinámico de productos organizados por categorías (Alimentos, Accesorios, Dulces, etc.).
- Filtrar y buscar productos en tiempo real.
- Gestionar un carrito de compras dinámico (agregar, eliminar, modificar cantidades y calcular el total de la compra).
- Acceder a una interfaz responsiva.

---

## Tecnologías utilizadas

- **[React](https://react.dev/) (v18+)**: Biblioteca de JavaScript para construir interfaces de usuario mediante componentes reutilizables.
- **[Vite](https://vitejs.dev/)**: Herramienta de desarrollo y empaquetado rápida y liviana.
- **Bootstrap**: Framework CSS para el desarrollo de interfaces modernas y responsivas.

## Instalación y ejecución

Sigue estos pasos para ejecutar el proyecto en tu computadora.

### Prerrequisitos

Tener instalado:

- **Node.js** (versión 16 o superior recomendada)
- **npm** (incluido con Node.js)

### 1. Clonar el repositorio

```bash
git clone https://github.com/franco-pajello/tiendaConReact.git
```

### 2. Acceder al directorio del proyecto

```bash
cd tiendaConReact
```

### 3. Instalar las dependencias

```bash
npm install
```

### 4. Ejecutar el proyecto

```bash
npm run dev
```

Luego, abre tu navegador e ingresa a la dirección que aparece en la terminal, normalmente:

```text
http://localhost:5173
```
